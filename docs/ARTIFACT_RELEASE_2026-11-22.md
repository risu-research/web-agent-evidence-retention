## Data boundaries and citation

The release contains the paper's 600-action numeric evidence and 598-action sensitivity, exact candidate and Replay XPath provenance, 70 residual collision mechanisms, source hashes, reproducibility scripts and frozen dependencies. Original WebLINX images, HTML, sessions, literal locator data, browser Trace archives, and exploratory R5–R8B work are excluded.

The MIT license covers original code. WebLINX source data have CC BY-NC-SA 4.0 and additional publisher terms, described in [DATASET_TERMS.md](DATASET_TERMS.md).
